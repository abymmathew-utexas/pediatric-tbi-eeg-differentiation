# Contributing Guide

## Branching
- Use feature branches named `feature/<short-description>`.
- Open pull requests to `main`.

## Commit Style
- Keep commits focused and descriptive.
- Prefer clear messages such as `Add EEG artifact removal baseline`.

## Development Setup
1. Create a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run tests with `pytest`.

## Pull Request Expectations
- Explain motivation and scope.
- Link relevant issues.
- Include test evidence.
- Confirm no PHI/PII is introduced.

## Clinical and Ethical Review
Model outputs should not be presented as clinical recommendations. All analyses should be reviewed with clinical mentors.
